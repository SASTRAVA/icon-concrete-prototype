# Icon Concrete interactive prototype

Standalone Vite/React website prototype for Icon Concrete's ready-mix concrete business.

## Development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The pour planner lets visitors select a structure, grade, delivery support, plant and estimated volume. The quote flow prepares a WhatsApp message for the visitor to review and send.
